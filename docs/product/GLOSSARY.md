# ReachRun Domain Glossary

> Authority：领域术语、允许用语与避免用语的唯一权威来源
>
> Read when：任务涉及资产模型、结果状态、用户文案、持久化字段或公开说明
>
> Update when：新增领域概念，或既有概念的名称、简短含义、允许用语发生变化

本文件只锁定名称、简短含义以及允许或避免的措辞。枚举取值、状态转换、持久化和判定行为由 [`PRD.md`](PRD.md) 的对应章节规定。发生冲突时，名称与措辞以本文件为准，产品行为以 PRD 为准。

ReachRun 负责从用户当前网络体检其固定互联网资产，并用克制、可解释的语言描述可用性、变化与故障层级。

正式产品名只使用英文 `ReachRun`；仓库名与终端命令统一为 `reachrun`。

## Language

**资产**：
用户希望保存并重复体检的对象。V1 只有域名资产和服务器资产。
_Avoid_: 检测项、目标、资源

**域名资产**：
以稳定 ID 为身份、以 hostname 为关键配置，用于观察公开解析和网站访问路径的资产。
_Avoid_: URL、网站地址、域名目标

**服务器资产**：
以稳定 ID 为身份；备注名、公网 IP 和预期服务端点都是可编辑属性。
_Avoid_: IP 资产、主机目标、VPS 项

**服务端点**：
服务器上一个需要独立判断可用性的具体协议与端口组合，例如 SSH 22 或 HTTPS 443。
_Avoid_: 开放端口、IP 连通性

**公开网站路径**：
客户端按照域名正常解析并访问网站的用户实际路径，可能经过 Cloudflare 等代理网络。
_Avoid_: 默认路径、正常访问

**源站直连**：
绕过代理网络并连接指定服务器 IP，同时保留正确 Host/SNI 的诊断路径。
_Avoid_: 强制访问、绕过 DNS

**快速体检**：
默认执行、优先回答资产当前是否可用的低成本检测阶段。
_Avoid_: 快速模式、浅检测

**深度诊断**：
只对异常、变化或证据不足资产执行的进一步对照检测阶段。
_Avoid_: 完整扫描、高级检测

**参考解析**：
由明确的公共 DNS/DoH resolver 返回、用于对照但不被视为事实真值的解析结果。
_Avoid_: 干净解析、可信 IP、正确答案

**最近观测摘要**：
最近一次正常完成的“检测全部”中，每个资产的粗粒度结果与观测时间，包括“无法判断”。它用于重新打开应用后的当前展示，不构成长期检测历史。
_Avoid_: 最新历史、检测记录

**比较基线摘要**：
每个资产最后一个可比较的有效粗粒度状态，用于计算新增异常、已恢复和持续异常；它可能早于最近观测摘要。单项或局部重测不覆盖它。
_Avoid_: 历史数据库、趋势基线

**检测状态**：
描述当前配置是否已有正式结果，包括待首次检测、配置已变更待检测、检测中、已完成和本批次已取消；检测前状态不伪造连通性结论。
_Avoid_: 空结果、未知健康状态

**连通性主结果**：
只描述网络与协议链路是否建立，取值包括链路可达、部分可达、未建立服务链路、未确认 Web 入口和无法判断；不代替业务内容健康判断。“未建立服务链路”仍需用证据区分超时、拒绝和协议失败，不等于整个 IP 路径不可达。
_Avoid_: 可用状态、健康分数

**当前关注状态**：
描述本轮结果是否需要用户关注，取值为无需关注、需关注或本次无法判断。它与连通性主结果分开，因此 HTTP 5xx 可以同时是“链路可达”和“需关注”。关注原因随比较基线摘要保存，例如一个原本存在的 Web 入口持续消失时，不会在下一轮被误报为已恢复。
_Avoid_: 告警级别、故障结论

**变化状态**：
当前粗粒度结果与比较基线摘要之间的关系，包括首次检测、新增异常、已恢复、持续异常、状态变化、无变化和本次无法比较。
_Avoid_: 趋势、告警状态

**高可信本地解析路径异常**：
系统/本地解析候选失败、独立参考候选在同等 Host/SNI 条件下成功，并已尽可能排除合法 CDN/GeoDNS 差异的结论。
_Avoid_: DNS 已污染、DNS 被劫持
